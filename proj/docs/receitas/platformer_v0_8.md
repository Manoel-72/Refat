# Receita V0.8 — Platformer simples

## Componentes mínimos
- Player: `Transform`, `Sprite`, `Animator`, `RigidBody2D`, `Velocity`, `BoxCollider`, `Script`
- Câmera: `Transform`, `Camera2D`
- HUD: `TextLabel`

## Script exemplo
```rs2
@start_message Player pronto
@player_controller 220
@camera_follow
```
