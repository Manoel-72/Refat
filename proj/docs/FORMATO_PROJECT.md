# project.json

```json
{
  "name": "Meu Projeto",
  "initial_scene": "assets/scenes/main.scene.json",
  "engine_version": "V0.8"
}
```

## Campos
- `name`: nome do projeto.
- `initial_scene`: caminho relativo da cena inicial carregada pelo editor/runtime.
- `engine_version`: versão da engine usada como referência.
