# Como criar UI Canvas e partículas (V0.9.4)

## UI Canvas
Use o prefab `assets/prefabs/ui_canvas_basic.prefab.json`.
Ele cria um painel screen-space no topo com um título.

## Partículas
Use o prefab `assets/prefabs/particle_source_basic.prefab.json`.
Ele já vem com o script `assets/scripts/particle_emitter.lua`.

## Atalho na cena demo
- `Enter` ou `E`: cria um inimigo novo
- O bloco ciano já é um emissor automático de partículas
